# Example playlists

These were made by **Generate playlist** from my own card, which has 38 albums. All three files list the same albums in play order, taken from folder names like `07 - John Coltrane - My Favorite Things`.

| File | What it is |
|---|---|
| [tecsun-playlist.epub](tecsun-playlist.epub) | For an e-reader, made for the XTEINK X4. The cover shows the first albums. Page one is the album list, and after it each album gets a chapter with its tracks |
| [tecsun-playlist.pdf](tecsun-playlist.pdf) | To print at 100% on US Letter. Cut the sheet down the middle, then fold a half into a 5.5 × 4.25 in card that tucks into the radio's case. The other half is a spare |
| [tecsun-playlist.html](tecsun-playlist.html) | A single web page for any browser. The album list fills the first screen, but on a tall window the page leaves no more than about 400 px of space below it. Each album in the list links to its row further down, which shows its tracks and play times. The list uses up to four columns in a wide window and two in a tall one, and the page follows your system's light or dark mode |

GitHub can't show an EPUB or a web page here, so download them to have a look.
